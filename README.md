# 📝 iOS Task Management & Todo App

A modern, high-performance **Task Management & Todo iOS Application** built with **SwiftUI**, **Core Data**, and **UserNotifications**.

Featuring a sleek **Dark Violet / Purple** theme inspired by Apple Human Interface Guidelines (HIG), with haptic feedback, custom floating action navigation, dynamic date calendar strips, and offline persistence.

---

## ✨ Features

- **Dashboard Overview**: Live task completion metrics, progress ring, and status badges (Done, In Progress, Overdue).
- **Interactive Calendar Strip**: Quick date selector with dynamic daily task breakdowns.
- **Priority & Categorization**: Multi-tag categorization (Design, Development, Research, Wireframe) with color-coded priority levels.
- **Offline Persistence**: Powered by Core Data with automatic background context merging.
- **Deadline Reminders**: Integrated local notifications scheduling via `UserNotifications`.
- **Haptic Feedback**: Custom spring animations and tactile feedback on task completion.
- **Floating Curved Tab Bar**: Smooth navigation across Home, Calendar, Quick Add, Activity Log, and Profile views.

---

## 🛠️ Tech Stack

- **Language**: Swift 5
- **Framework**: SwiftUI (iOS 16+)
- **Database / Storage**: Core Data (`.xcdatamodeld`)
- **Notifications**: UserNotifications Framework
- **Architecture**: MVVM
- **Tooling**: Xcode 14+

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone git@github.com:Khulfan42/mytodoapp.git
   ```
2. Open `mytodoapp.xcodeproj` in Xcode:
   ```bash
   open mytodoapp.xcodeproj
   ```
3. Select an iOS Simulator (e.g. iPhone 14/15/16) or physical iOS device and press **`Cmd + R`** to run.
